# Feature Specification: 清理遗留界面文案

**Feature Branch**: `[002-clean-legacy-copy]`

**Created**: 2026-07-26

**Status**: Draft

**Input**: User description: "由于原仓库有部分葡萄牙语和 Oasis 文案，我希望深度清楚：用户可见界面不存在未授权的葡萄牙语和 Oasis 文案；中文为默认语言；保留确有用途的英文技术词；不修改腾讯官方网页内容；不误删日志、协议、第三方文件和代码中的必要 Unicode；文案清理不改变登录、Session、导航和 Flash 行为。后续补充：将启动器自有日志模板纳入修改范围，固定模板统一使用便于检索和定位的英文；保留原始外部错误、结构化字段、历史日志和脱敏边界。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 获得干净的中文默认界面 (Priority: P1)

作为腾讯国服玩家，我希望首次启动、日常管理、加载、提示和错误恢复界面默认使用中文，且看不到旧项目遗留的葡萄牙语或 Oasis 文案，从而明确自己使用的是面向腾讯国服的启动器。

**Why this priority**: 这是用户最先感知的产品身份和可用性问题；任何遗留文案都会造成产品归属、登录目标和操作含义的混淆。

**Independent Test**: 使用全新配置启动应用，逐一打开启动器自有的首次设置、管理、加载、提示、错误和恢复界面，即可独立确认默认语言以及葡萄牙语/Oasis 可见项是否为零。

**Acceptance Scenarios**:

1. **Given** 用户在没有既有语言配置的环境中首次启动，**When** 任一启动器自有界面首次出现，**Then** 通用操作文案以中文显示，且无需用户先选择中文。
2. **Given** 用户遍历启动器自有的常规、空状态、加载中、失败和恢复界面，**When** 检查可见文本、窗口标题、提示、工具提示和辅助访问文本，**Then** 不出现启动器编写的葡萄牙语或 Oasis 文案。
3. **Given** 既有配置缺少语言值、语言值无效或保存了已淘汰的葡萄牙语值，**When** 用户升级后启动，**Then** 界面安全回退为中文，且其他 Profile 与偏好数据保持不变。

---

### User Story 2 - 保留必要的技术表达和受保护内容 (Priority: P2)

作为需要理解状态或排查故障的用户与维护者，我希望 Flash、GPU、Session 等确有用途的英文技术词保持准确，启动器自有日志模板使用稳定、可搜索且不会因常见终端编码产生乱码的英文，同时官方网页、原始外部错误、历史日志、协议、第三方资产和代码中的必要 Unicode 不因清理被误改或删除。

**Why this priority**: 清理必须提升一致性，而不能以牺牲技术准确性、审计证据、第三方完整性或文本编码安全为代价。

**Independent Test**: 对所有命中的葡萄牙语、Oasis、英文和非 ASCII 文本进行来源与可见性分类；检查运行中由启动器生成的固定日志模板均为可搜索的 ASCII 英文，核对每个动态或受保护保留项的理由，并比较受保护内容在清理前后的完整性。

**Acceptance Scenarios**:

1. **Given** 用户可见文案包含没有自然、准确中文替代的技术术语，**When** 该术语有明确用途并被列入保留清单，**Then** 可保留英文原词，并由中文上下文说明其含义或状态。
2. **Given** 腾讯官方网页在启动器窗口中加载，**When** 文案清理后的版本运行，**Then** 官方网页的文字、结构、交互和返回内容不被翻译、替换、隐藏或注入修改。
3. **Given** 运行中的启动器记录配置、窗口、Profile、Session、导航、Flash、性能或诊断事件，或者生成面向开发者的异常摘要，**When** 维护者查看控制台、日志文件或开发诊断结果，**Then** 由启动器编写的固定文本使用简洁一致的 ASCII 英文，能够直接检索组件、动作、结果和失败阶段，不包含葡萄牙语、中文固定模板、表情或装饰性 Unicode。
4. **Given** 匹配项位于外部原始错误、动态路径或名称、结构化字段、历史日志文件、协议标识、第三方文件、历史记录、测试证据、代码注释或必要 Unicode 中，**When** 它不是启动器编写的固定日志模板或用户可见文案，**Then** 不得仅因语言、编码或关键字命中而删除或改写。
5. **Given** 外部系统返回必须保留的原始技术错误，**When** 启动器需要向用户说明失败，**Then** 启动器提供中文说明，同时原始技术信息只在既有安全、脱敏和可见性边界允许的技术详情或日志中保持可诊断性。

---

### User Story 3 - 清理后仍可正常登录和进入游戏 (Priority: P3)

作为多账号玩家，我希望界面文案清理不改变扫码登录、Profile Session 隔离、页面导航、选服和 Flash 游戏加载，从而无需承担与视觉清理无关的功能回归风险。

**Why this priority**: 文案属于表现层变化，但登录、Session、导航与 Flash 是启动器的核心能力；必须用回归验收证明两者解耦。

**Independent Test**: 在两个独立 Profile 中分别完成腾讯官方扫码、手动选服和 Flash 游戏进入流程，并执行既有刷新、失败恢复和窗口操作验收，即可独立判断行为是否保持。

**Acceptance Scenarios**:

1. **Given** 一个全新 Profile，**When** 用户从中文启动器界面发起游戏并完成官方扫码和手动选服，**Then** 导航进入 Flash 游戏的步骤、窗口关系和结果与清理前一致。
2. **Given** 两个不同 Profile，**When** 用户分别登录或恢复会话，**Then** 两者的 Session 和登录状态继续相互隔离。
3. **Given** 页面失败、Session 失效或用户执行既有刷新操作，**When** 启动器进行恢复，**Then** 原有有界恢复行为保持，不新增无限重试、跨 Profile 状态复制或 Oasis 回退。

### Edge Cases

- 葡萄牙语或 Oasis 出现在历史文档、既有日志文件、变更记录、负向测试断言或安全约束中时，属于事实与防回归证据，不应被当作当前模板残留批量删除。
- 相同文案可能同时存在于默认 HTML、运行时翻译表、动态拼接文本、窗口标题、原生对话框、托盘/菜单、通知、辅助访问属性或安装/卸载入口；只修改其中一个副本不得视为清理完成。
- 既有用户保存了葡萄牙语语言代码时，回退中文不得重置 Profile、Session、窗口偏好或其他无关配置。
- 英文品牌名、协议名、文件扩展名、缩写和原始错误标识可能包含非中文字符；只有通用界面用语需要翻译，技术标识不得按字符集批量删除。
- 官方腾讯页面、操作系统或第三方组件可能展示其自身文本；必须依据内容所有者和修改边界分类，不能用页面注入或全局字符串替换强制中文化。
- Unicode 符号、中文标点、表情、地区字符、转义序列或用于测试编码边界的样本即使不是 ASCII，也不得在没有逐项理由时清除。
- 用户不可见的葡语代码注释、测试说明或外部原始错误可能与启动器模板使用相同词汇；扫描结果必须结合所有者与静态/动态边界判定。活动生产代码中由启动器编写的固定日志模板不再属于该保留例外。
- 日志模板可能由固定文本与动态路径、Profile 名或错误消息拼接而成；只英文化固定文本，不得为满足 ASCII 检查而删除、音译或清洗动态值。
- 安装器、卸载器、桌面快捷方式或导出文件名在应用主窗口之外可见，仍属于启动器自有的用户可见产品面。

## Requirements *(mandatory)*

### Scope

**In Scope**:

- 启动器自有且可能展示给用户的首次设置、管理、加载、游戏宿主外壳、原生提示与错误、恢复提示、窗口标题、菜单、托盘、通知、工具提示、辅助访问文本、安装/卸载提示、桌面入口和用户导出入口。
- 活动生产路径中由启动器编写的控制台与文件日志固定模板、启动横幅、异常摘要和开发者诊断文本，包括配置、Profile、Session、窗口、导航、Flash、性能、诊断和恢复事件。
- 默认语言选择、缺失或无效语言值的回退，以及既有葡萄牙语配置升级后的安全迁移。
- 对遗留文案候选的来源、可见性、处置方式和保留理由进行审计，并建立可重复的自动检查与人工验收。

**Out of Scope**:

- 翻译、隐藏、重排或注入修改腾讯官方网页及其子页面内容。
- 回写或清洗既有日志文件、外部原始错误、动态路径/Profile 名、结构化字段、历史文档、变更记录、协议内容、第三方文件、测试证据和纯代码注释中的语言痕迹；除非它们被证明是活动生产代码中由启动器编写的固定模板或会直接成为用户可见文案。
- 决定葡萄牙语之外的其他可选本地化是否长期保留；但它们不得影响中文作为默认语言。
- 改造登录方式、Session/Partition 策略、页面导航规则、选服方式、Flash 接入、网络策略、自动化能力或运行时依赖。

### Definitions

- **启动器自有的用户可见文案**: 由本项目提供、可在正常操作、错误、恢复、安装卸载或辅助访问流程中直接呈现给用户的文本。
- **未授权葡萄牙语/Oasis 文案**: 任何由启动器提供且可触达用户的葡萄牙语通用界面文案，或任何把 Oasis/国际服品牌、入口、地区、服务器、登录方式当作当前产品能力呈现的文案。此类文案在启动器自有界面中的允许数量为零。
- **开发者运行文本**: 活动生产代码中由本项目编写并在日志、启动横幅、异常摘要或开发诊断结果中输出的固定文本部分；不包括拼接进入模板的动态路径、Profile 名、外部错误消息或结构化字段值。开发者运行文本使用英文是为了跨语言检索和故障定位，不跟随界面语言切换。
- **受保护内容**: 腾讯官方页面内容，以及既有日志文件、外部原始错误、动态日志值、协议标识、第三方文件、历史证据、测试样本、代码注释和必要 Unicode。受保护内容不因关键字或字符集命中而自动进入修改范围。
- **允许的英文技术词**: 为准确表达产品能力、系统状态或故障信息而必须保留的英文专有名词、缩写或协议名称，例如 Flash、GPU、CPU、Session、Profile、URL、SWF、PPAPI。每个实际保留类别必须有明确理由并保持一致用法。

### Functional Requirements

- **FR-001**: 项目 MUST 建立启动器自有用户可见面的完整清单，并至少覆盖常规、首次启动、空状态、加载、错误、恢复、辅助访问、安装卸载和系统集成入口。
- **FR-002**: 每个葡萄牙语或 Oasis 候选项 MUST 被分类为“替换”“删除可见入口”或“受保护保留”，并记录其来源、用户可见性和处置理由。
- **FR-003**: 在没有有效用户语言选择时，启动器所有自有界面 MUST 默认使用简体中文。
- **FR-004**: 缺失语言值、无效语言值和已淘汰的葡萄牙语语言值 MUST 回退为简体中文，且 MUST NOT 清除或重建无关的 Profile、Session 或用户偏好。
- **FR-005**: 启动器自有的语言选择入口 MUST NOT 再把葡萄牙语作为可选产品语言呈现给用户。
- **FR-006**: 启动器自有的默认中文路径 MUST NOT 展示葡萄牙语通用界面词、句子、语言代码或葡萄牙语专属本地化标签。
- **FR-007**: 启动器自有的常规、失败和恢复路径 MUST NOT 展示 Oasis 品牌、国际服入口、国际服地区/服务器或其登录能力。
- **FR-008**: 文案清理 MUST 覆盖静态默认文本、运行时文案、动态拼接文本、窗口标题、原生对话框、菜单/托盘、通知、工具提示和辅助访问文本，不能仅检查主页面可见节点。
- **FR-009**: 安装、卸载、桌面入口、快捷方式和用户导出入口中的启动器自有文案 MUST 遵守相同的中文默认与遗留文案清理规则。
- **FR-010**: 通用操作、说明和错误恢复文案 MUST 使用中文；英文只能在表达技术专有名词、缩写、协议、文件类型或不可安全翻译的原始技术标识时保留。
- **FR-011**: 每个允许保留的英文技术词类别 MUST 有可审查的必要性说明；同一概念 MUST 在不同可见面保持一致写法，并在可能引起理解困难时提供中文上下文。
- **FR-012**: 腾讯官方网页的文本、DOM、样式、资源、交互、跳转目标和服务端响应 MUST NOT 因本功能被翻译、替换、隐藏、拦截或注入修改。
- **FR-013**: 对官方网页内容的扫描结果 MUST 与启动器自有文案分开处理；官方内容中的任意语言或品牌文本不得计入启动器自有文案清理失败。
- **FR-014**: 日志记录能力、日志级别、调用位置、诊断上下文、动态值、结构化字段和既有脱敏边界 MUST 保持；活动生产代码中由启动器编写的日志模板、启动横幅、异常摘要和开发者诊断固定文本 MUST 使用简洁一致的 ASCII 英文，既有日志文件、外部原始错误、历史记录和测试证据 MUST NOT 因匹配而被删除或回写。
- **FR-015**: 协议标识、URL 角色、第三方文件、许可内容、二进制资源、代码标识符、转义序列和必要 Unicode MUST NOT 通过全局替换、非 ASCII 清洗或无逐项依据的批量删除来处理。
- **FR-016**: 若外部原始错误文本需要保留以供诊断，启动器面向用户的说明 MUST 为中文；原始错误 MUST 继续遵守现有安全、脱敏和可见性边界。
- **FR-017**: 文案清理 MUST NOT 改变腾讯官方扫码认证、手动选服、顶层导航、认证子窗路由、Session 获取或失效、窗口生命周期和 Flash 加载行为。
- **FR-018**: 不同 Profile MUST 继续使用相互隔离的 Session；语言迁移、文案加载和错误恢复 MUST NOT 造成跨 Profile 状态读取、写入、复制或清理。
- **FR-019**: 页面失败和 Session 失效后的恢复 MUST 保持有界，且 MUST NOT 新增 Oasis/国际服回退、无限刷新或无限重试。
- **FR-020**: 本功能 MUST NOT 升级 Node.js、npm、Electron、Flash 接入方式或核心依赖，也 MUST NOT 无需求地改写依赖锁定文件。
- **FR-021**: 自动检查 MUST 能识别启动器自有可见面中的葡萄牙语、Oasis 与失效默认语言回归，同时通过明确排除或允许清单避免把受保护内容当作删除目标。
- **FR-022**: 人工验收 MUST 覆盖全新配置、遗留葡萄牙语配置、常规管理、加载、至少一个失败/恢复路径、安装卸载入口，以及两个 Profile 的腾讯登录与 Flash 启动流程。
- **FR-023**: 交付物 MUST 提供审计结果，使评审者能够逐项确认已修改的可见文案、保留的技术词、受保护命中项和行为回归结果。
- **FR-024**: 自动检查 MUST 覆盖活动生产代码中的全部启动器自有日志调用、启动横幅、异常摘要和开发者诊断文本，并拒绝固定文本中的葡萄牙语、中文、Oasis 当前品牌、表情、装饰性 Unicode 和非 ASCII 标点；动态值与原始错误 MUST 与固定文本分开判定。
- **FR-025**: 日志英文化 MUST NOT 改变日志调用数量、级别、控制流、返回值、异常处理、结构化字段、脱敏、文件传输或控制台传输配置；启动摘要 MUST 使用当前产品名，并使配置、Profile、Session、导航、Flash 和恢复阶段能够按英文关键词定位。

### Key Entities

- **界面文案项**: 一个可能呈现给用户的文本单元；关键属性包括所属产品面、触发路径、内容所有者、默认语言、是否动态生成、可见性和清理结论。
- **保留例外**: 一个未被中文化或删除的匹配项；关键属性包括类别、原始内容、保留理由、用户可见性、安全边界和对应审查证据。
- **语言配置状态**: 决定启动器自有界面语言的用户状态；包括全新、有效中文、缺失、无效和遗留葡萄牙语等情况，并与其他 Profile/Session 数据相互独立。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 启动器自有用户可见面清单中的项目 100% 完成检查与分类，未分类候选项数量为 0。
- **SC-002**: 对全新配置、缺失语言值、无效语言值和遗留葡萄牙语值四类启动场景抽查时，100% 的启动器自有首次可见界面无需额外选择即显示简体中文。
- **SC-003**: 对全部启动器自有常规、错误、恢复、安装卸载和辅助访问入口检查时，未授权葡萄牙语文案数量为 0，Oasis 当前产品文案数量为 0。
- **SC-004**: 所有保留的英文技术词类别 100% 具有必要性说明和一致用法；不存在以“技术词”为名保留的普通英文操作文案。
- **SC-005**: 受保护命中项 100% 具有保留分类；腾讯官方网页内容因本功能产生的文字、结构或交互改动数量为 0，第三方与协议资产的无依据改动数量为 0。
- **SC-006**: 与登录、Session 隔离、导航、窗口生命周期和 Flash 相关的既有验收场景通过率不低于清理前基线，且本功能引入的新失败数量为 0。
- **SC-007**: 使用至少两个独立 Profile 完成扫码、手动选服和 Flash 进入的人工回归时，成功流程为 2/2，跨 Profile 登录态污染事件为 0。
- **SC-008**: 评审者可仅依据审计结果逐项说明每个候选项“为什么修改或为什么保留”，无法追溯到清理规则的文案改动数量为 0。
- **SC-009**: 活动生产路径中开发者运行固定文本的 ASCII 英文覆盖率为 100%，葡萄牙语、中文固定模板、Oasis 当前品牌和可能产生乱码的装饰符号数量均为 0。
- **SC-010**: 使用默认中文界面完成一次启动、扫码进入游戏和刷新后，维护者能够从日志中按英文组件或阶段词定位配置加载、Flash 搜索、Profile、Session、导航与刷新事件；因本次模板修改丢失的日志事件、级别、动态上下文或结构化字段数量为 0。

## Assumptions

- “中文为默认语言”解释为简体中文；用户未要求在本功能中决定葡萄牙语之外其他可选本地化的长期去留。
- 启动器自有界面和活动生产日志固定模板中的葡萄牙语没有业务上必须保留的例外；必要的葡萄牙语历史证据只存在于既有日志、测试、文档、注释或第三方/官方内容中。
- Oasis 可以在历史文档、安全约束和负向测试中作为已移除对象被提及，但不得在启动器自有用户界面中作为当前品牌、入口或能力出现。
- 允许的英文技术词以准确性和用户理解为判断标准，不等同于允许保留普通英文按钮、说明或错误提示。
- 腾讯官方网页继续由腾讯控制；本功能只清理启动器自有产品面，不以任何方式替腾讯页面做本地化。
- 日志固定模板统一采用英文且不随界面语言切换；界面继续默认中文，二者服务于不同的用户理解与跨语言故障检索场景。
- 现有登录、Session、导航、Flash、日志级别、动态上下文、脱敏和诊断规则是回归基线，本功能不重新定义这些行为。
