Dev Tools (v5.0) SHINOBI_DEBUG · tempmail + API login + inspector + JWT
Criar conta tempmail
Cria email temporário (mail.tm) + registra no Naruto Online via API. Retorna JWT de 2h — sem Flash, sem CAPTCHA, sem verificação de email.
Login via API
Autentica via passport.oasgames.com e injeta cookie oas_user na session do perfil selecionado.
Decodificador JWT
Cole um token JWT para visualizar o header e payload decodificados com syntax highlighting.
Inspector de Rede
Captura requisições HTTP do jogo via webRequest. Mostra URLs, cookies oas_user capturados (JWT decodificado) e estatísticas.
Source Extractor + DevTools
Extrai o HTML da página Flash, lista cookies, recarrega a sessão (F5) e abre DevTools (F12).
